# 项目所有者复现清单

最终投递简历前，项目所有者必须亲手完成以下操作并能够解释结果：

- [ ] 从干净 Clone 安装并启动项目。
- [ ] 配置一次本地开发环境和所有服务端环境变量。
- [ ] 上传一份新文档并观察解析、清洗和切块。
- [ ] 在数据库中找到对应向量、Embedding 版本和来源元数据。
- [ ] 运行一次真实问答并定位每条引用。
- [ ] 手动触发一次订单查询 Tool Call。
- [ ] 修改一条退货政策并观察确定性结果变化。
- [ ] 制造一个无答案问题并验证拒答和人工接管。
- [ ] 运行评测集并解释至少一个失败案例。
- [ ] 在没有 AI 提示的情况下完成三分钟演示。

## 当前可执行项

- [ ] 运行 `pnpm install`。
- [ ] 运行 `pnpm env:check`，解释 offline 与 connected 模式的区别。
- [ ] 阅读初始迁移，指出 Workspace RLS、向量版本和混合检索函数。
- [ ] 阅读 Seed，解释订单日期为什么不会随时间失效。
